# news-image-20261119

One image summing up Thursday 19 November 2026's world news for the make.fun bounty.

## What it shows

- APEC Shenzhen trilateral summit
- US strike on an Iranian missile site on Qeshm island
- An oil tanker attacked in the Strait of Hormuz with one crew member missing
- A new Israeli operation in central Gaza
- Gold slipping below $3,800 an ounce at a 14-month low

## Run

Copy the bundled image into a local output directory:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The image is a static 1024x1024 PNG under 1 MiB, and both grader runs produce byte-identical output.
